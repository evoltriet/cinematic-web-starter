# Experience Plan

Last updated: 2026-08-20

## First-viewport promise

Show that cinematic depth and accessible interaction can coexist, then invite visitors into a concise field guide.

## Chapter plan

| ID | Job | Motion mode | Mobile composition |
| --- | --- | --- | --- |
| `arrival` | Establish atmosphere and product promise | Reveal | Centered copy over simplified CSS scenery |
| `passage` | Demonstrate bounded local storytelling | Local scroll story | Sticky shortened story with complete fallback |
| `workflow` | Explain the agent protocol | Reveal | Sequential readable cards and code sample |
| `field-notes` | Teach runtime principles | Triggered passage | Stacked disclosure panels |
| `quiet-zone` | Demonstrate the backend boundary | Static | Single-column form |

## Primary action

The main action is to understand and clone the framework. The live experience links visitors to the workflow, source, and validation commands without interrupting reading.

## Responsive strategy

Every chapter has a mobile composition decision. Scenic traffic and depth decrease on small screens while semantic order, core copy, and controls remain complete.
