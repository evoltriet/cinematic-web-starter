# Recipe 05: Quality Assurance

## Required inputs

Built output, config budgets, browser matrix, and acceptance criteria.

## Required outputs

Structural, keyboard, reduced-motion, zoom, contrast, responsive, performance, privacy, and interaction evidence.

## Stop conditions

Stop release when any required gate fails or an exception lacks a named human approver.

## Context updates

Update `QA_REPORT.md` with commands, viewports, findings, and residual risk.

## Acceptance checks

`pnpm validate`, browser tests, and Lighthouse pass; a human reviews composition at every target viewport.
