# Recipe 04: Implementation

## Required inputs

Approved config, experience plan, design context, asset plan, and stable interfaces.

## Required outputs

Semantic content and controls first, followed by bounded Motion choreography and complete fallbacks.

## Stop conditions

Stop if essential content depends on hover, animation timing, or a motion-only state.

## Context updates

Update current implementation notes and document any approved config exception.

## Acceptance checks

Keyboard and reduced-motion flows work before decoration; forms stay quiet; public exports remain compatible.
