# Recipe 06: Release

## Required inputs

Approved QA evidence, release scope, publication authority, and rollback path.

## Required outputs

Updated context, changelog, migration guidance, release notes, tag, and published artifact.

## Stop conditions

Stop if privacy scanning, compatibility review, publication authority, or target verification is missing.

## Context updates

Update `PROJECT_CONTEXT.md`, `QA_REPORT.md`, `CHANGELOG.md`, and release notes.

## Acceptance checks

The published artifact matches the validated commit and existing consumers have clear migration guidance.
