# Security Policy

## Reporting

Do not open public issues for vulnerabilities or exposed personal data. Use GitHub’s private vulnerability reporting for this repository. If it is unavailable, contact the repository owner through the private contact method listed on their GitHub profile.

Include reproduction steps, affected versions, likely impact, and any suggested mitigation. Never include real credentials, tokens, or personal data in a report.

## Supported versions

Until `1.0.0`, only the latest tagged release receives security updates.
