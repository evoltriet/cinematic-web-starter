# Cinematic Web Starter 0.1.0

The first public release packages an accessible, mobile-first cinematic workflow into editable React + Motion source.

## Highlights

- Ceremonial opener with Skip, Replay, focus restoration, scroll locking, and reduced-motion handling.
- Semantic handwriting-style ink reveal without GIFs, canvas, or rasterized text.
- Responsive backdrops, contained depth planes, forward-running triggered passages, and a local horizontal story primitive.
- Intersection-driven navigation plus accessible tabs and accordion examples.
- CSS-only fictional demo with no private project assets or copied marketplace code.
- Durable context templates, design and motion guidance, responsive QA checklists, backend adapter boundaries, and an anonymous production case study.
- Automated lint, types, tests, build, browser QA, Lighthouse, bundle budgets, privacy scan, GitHub Pages, and release workflows.

## Boundaries

This is a cloneable frontend starter, not an npm package or full-stack backend. Applications provide their own persistence, authentication, email, scheduling, and hosting adapters.
